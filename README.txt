GITHUB PAGES:
1. Create a public GitHub repository, e.g. Shifana_weds_Althaf.
2. Upload ALL files and the assets folder. Keep index.html at the top level.
3. Repository -> Settings -> Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select branch "main" and folder "/ (root)", then Save.
6. GitHub will provide the live URL:
   https://YOUR-USERNAME.github.io/Shifana_weds_Althaf/

The site is a static HTML/CSS/JavaScript site and does not need a server.
